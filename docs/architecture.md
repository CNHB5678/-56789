## 核心组件

### 1. 数据面 (Data Plane)
- **APISIX 网关**: 负责请求转发、限流、熔断、鉴权
- **特性**: 数据面与控制面完全解耦，控制面故障不影响流量
- **部署**: 3 副本，跨可用区高可用
- **性能**: 单实例 QPS ≥ 30 万

### 2. 控制面 (Control Plane)
- **配置中心**: Nacos 集群，负责配置存储和分发
- **Dashboard**: APISIX Dashboard，可视化管理
- **部署**: 3 副本，读写分离

### 3. 依赖组件
- **Redis Cluster**: 6 节点，3 主 3 从，跨可用区部署
- **PostgreSQL**: 1 主 2 从，复制延迟监控
- **Nacos**: 3 节点集群，配置和服务发现

### 4. 可观测性栈
- **Prometheus**: 指标收集
- **Grafana**: 可视化监控
- **Loki**: 日志聚合
- **SkyWalking**: 链路追踪

## 核心能力

### 1. 流量治理
- 分布式限流（滑动窗口、令牌桶、漏桶）
- 熔断降级（健康检查、错误率阈值）
- 灰度发布（按比例、按请求头）
- 流量镜像（复制流量到测试环境）

### 2. 安全防护
- 多重鉴权（JWT、OAuth、API Key）
- IP 黑白名单
- WAF 防护（SQL注入、XSS）
- HTTPS 强制加密（TLS 1.2+）

### 3. 多租户隔离
- 租户级配置隔离
- 资源限制（连接数、QPS）
- 独立的监控和计费

### 4. 高可用设计
- 数据面无状态，支持水平扩展
- 同城双活，跨可用区部署
- 异地灾备，RPO < 1s，RTO < 5min
- 自动故障恢复，无需人工干预

## 性能优化

### 1. 内核参数优化
```bash
# 文件描述符限制
fs.file-max = 1048576

# 网络栈优化
net.core.somaxconn = 65535
net.core.netdev_max_backlog = 65536
net.ipv4.tcp_max_syn_backlog = 65536
net.ipv4.tcp_tw_reuse = 1
net.ipv4.tcp_max_tw_buckets = 20000
net.core.rmem_default = 262144
net.core.rmem_max = 16777216
net.core.wmem_default = 262144
net.core.wmem_max = 16777216
```

### 2. APISIX 优化
- 开启 CPU 亲和性
- 启用 JIT 编译
- 优化 worker 数量
- 减少插件性能损耗

### 3. 缓存优化
- 热点数据本地内存缓存
- Redis 集群分片
- L2 缓存预热
